# Documentation

The repository root contains everything needed to run the experiments. This
folder contains optional background material:

- [`datasets.md`](datasets.md): a short description of LoCoMo and PersonaMem-v2.
- [`personamem.md`](personamem.md): the PersonaMem-v2 protocol and pilot result.
- [`methodology.md`](methodology.md): important choices and limitations.
- [`reports/`](reports/): the current HTML evaluation report and raw-report
  manifest. The PDF in that folder is an older July 26 snapshot.

Start with the main [`README`](../README.md) if you only want to run the code.
