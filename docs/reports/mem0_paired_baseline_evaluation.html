The updated incremental pairwise protocol significantly boosted Text Memory F1 from 13.96% to 38.22% (+24.26 points) and achieved 70.0% accuracy on the paper's binary LLM judge prompt. Temporal questions showed the largest gain (27.46% → 56.94%).

Interpretation

  • Text memory performance jumped significantly (+24.26 F1) when switching to paper-aligned incremental pairwise ingestion and rolling 5-pair summaries.
  • LLM judge scoring (70.0% accuracy) demonstrates strong answer quality beyond token-level F1 matching.
  • Graph reduced stale-fact retrieval in controlled updates, but stale graph state and current-fact misses remained important failures.
  • Historical graph processing logged malformed deletion-extraction responses and search-tool errors during PersonaMem, although all 60 rows produced reports.
