Interpretation & Paper Alignment

  • Both Text and Graph Composite backends achieved high performance under the incremental pairwise protocol (+24.5 F1 over old session-level runner).
  • Graph Composite (mem0g) wins Multi-Hop & Open-Domain: Structured Neo4j triples (`source -[relationship]-> destination`) connect facts across dialogue sessions that pure text embeddings miss.
  • Text Memory wins Single-Hop: Dense natural language memory is more concise for single-turn facts, avoiding the prompt length overhead of graph relation lists.
  • Paper Consistency: These findings directly mirror the Mem0 paper ($\text{Mem0}^g$ paper section 4.1), where graph representations enhance multi-session relational context while text memory excels at concise single-turn spans.
